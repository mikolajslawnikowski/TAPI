# TAPI Introduction

API providing information about characters, fruits, and arcs from the One Piece universe.

## Technologies Used

- **Backend**:

  - Node.js with Express
  - GraphQL for flexible queries
  - REST API for traditional endpoints

- **Documentation**:
  - OpenAPI/Swagger
  - Docusaurus
